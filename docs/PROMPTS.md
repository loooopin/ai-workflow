# ai-workflow 提示词速查表

> 本文档汇总工作流的所有触发提示词与用法示例。
> 软链装好后（`scripts/install.sh`），在**任意项目**的 Cursor 会话里直接说这些话即可触发。
> 新会话才加载软链——刚装完建议开新会话再触发。

---

## 1. 主链路触发

### 功能开发（PRD 驱动，走全流程）

```
ai-workflow 新需求：（需求描述，或贴 PRD 文件路径 / 链接）
```

同义触发词："走流程"、"新需求"、"开发需求"、"启动工作流"，或直接给 PRD 并要求端到端完成。

流程：需求录入 → 澄清 → 设计评审 → 拆解/工时 → 编码 → 单测 → 质量自检 → 复盘（每关卡需确认）。

### 修 bug / 优化

```
ai-workflow bugfix：（现象描述，最好附 uid/roomId 等关键参数和首次出现时间）
```

同义触发词："修 bug"、"排查问题"、"线上问题"。公司项目自动对接日志/配置工具，非公司项目自动降级。

### 恢复中断的任务

```
ai-workflow --continue
```

同义："继续上次任务"。会从 `runtime/tasks/CURRENT` 恢复上下文，接着上次的阶段继续。

## 2. 快捷模式

| 提示词 | 效果 |
|--------|------|
| `ai-workflow-dev --light` | 轻量模式：跳过设计评审与拆解（适合 ≤5 文件小改动），仍走澄清、编码、自测、复盘 |
| `ai-workflow-bugfix --hotfix` | 热修模式：跳过完整复盘，只记一行到 hotfix 清单，事后补全 |
| 任意阶段说"跳过本阶段" | 跳过当前关卡（会记录在 state.md，需你确认） |

---

## 3. 单独节点触发（不走全流程）

| 提示词 | 触发节点 | 输入 |
|--------|---------|------|
| "出设计文档" / "设计评审" / "评审方案" | 设计评审（含独立子 Agent 对抗评审） | 需求规格或改动描述 |
| "拆解任务" / "预估工时" / "排期" / "分工" | 任务拆解与工时预估 | 设计文档或改动范围 |
| "复盘" / "retro" / "总结这次任务" | 复盘关卡 | 当前任务上下文 |
| "加载公司规范" / "amar 规范" | 手动加载公司适配层知识 | 无（非公司项目禁用） |
| "上线文档" / "发布清单" / "部署文档" / "出上线单" | 生成上线 checklist 文档 | 当前分支变更（公司仓库） |

## 4. 关卡中的常用应答

流程推进时 AI 会在关卡处等你确认，常用应答：

| 场景 | 你可以说 |
|------|---------|
| 澄清阶段，问题问完了 | "清楚了" / "就这样，继续" |
| 澄清阶段，AI 问偏了 | "不对，我的意思是……" |
| 设计评审，同意方案 | "批准" / "可以，继续" |
| 设计评审，有分歧 | "这里不同意：……"（AI 会修订或呈报裁决） |
| 拆解结果粒度不合适 | "任务 X 拆得太粗/太细" |
| 工时口径不认可 | "风险系数按 X 算" |
| 复盘时 AI 请你填问题 | **必须亲自填写**"本次 AI 的问题"，这是体系进化的输入 |
| 想中途换任务 | "切换到任务 XXX"（显式指定任务目录） |

## 5. 组合示例

**示例 1：拿到 PRD 开工**

```
ai-workflow 新需求：/Users/user/Documents/激励任务3.0-PRD.pdf
```

**示例 2：线上问题排查**

```
ai-workflow bugfix：用户反馈房间榜单数据不刷新，uid 12345678，今天下午 3 点开始出现，偶现
```

**示例 3：已有方案只要排期**

```
拆解任务：按 docs/xxx-design.md 拆解，要给测试同学联调排期
```

**示例 4：昨天没做完接着做**

```
ai-workflow --continue
```

## 6. 注意事项

- **触发词失效排查**：若 AI 没识别到 skill，说明会话未加载软链，重开一个会话窗口；或检查 `ls ~/.cursor/skills/ | rg ai-workflow` 是否有 6 个软链
- **公司/非公司自动识别**：进流程时会自动探测 pom 里的 `com.immomo` groupId 或 `ultron-*` 目录名，无需手动声明
- **红旗停表**：AI 遇到设计冲突、跨团队改动、新依赖、连续失败、需求遗漏时会停下来问你，这是设计行为，不要嫌它打断
- **复盘不可跳过**：任务结束前的复盘是强制关卡，花 2 分钟填"AI 的问题"能让下一轮更顺
